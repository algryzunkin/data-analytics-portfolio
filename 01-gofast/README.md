# GoFast — статистический анализ данных

**Задача:** изучить поведение пользователей сервиса аренды самокатов, рассчитать месячную выручку и проверить несколько бизнес-гипотез.

**Инструменты:** Python, pandas, NumPy, Matplotlib, SciPy.

**Что сделано:**
- подготовлены и объединены таблицы пользователей, поездок и подписок;
- исследованы различия в поведении пользователей по типу подписки;
- рассчитана выручка в разрезе пользователя и месяца;
- проверены статистические гипотезы;
- рассчитано количество промокодов для достижения плана по продлениям.

**Проверенный результат:** если вероятность продления равна 10%, минимальное число промокодов, при котором вероятность получить менее 100 продлений не превышает 5%, составляет **1161** (`P(X < 100) ≈ 0.0498`).

**Ограничения:** поездки одного пользователя зависимы, поэтому обычный t-test по отдельным поездкам следует интерпретировать осторожно. Данные относятся к 2021 году.

Для локального запуска CSV-файлы должны находиться в папке `data/` рядом с ноутбуком.
