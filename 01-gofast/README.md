# GoFast — анализ поведения пользователей и выручки

**Направление:** продуктовая аналитика · бизнес-метрики · статистика

## Бизнес-задача

Изучить поведение пользователей сервиса аренды самокатов с подпиской и без неё, рассчитать выручку и проверить гипотезы, полезные для развития подписочной модели.

## Что сделано

- Объединены данные о пользователях, поездках и подписках.
- Исследованы длительность и расстояние поездок, а также различия между группами пользователей.
- Рассчитана помесячная выручка на уровне пользователей.
- Проведены статистические проверки гипотез.
- Рассчитан необходимый масштаб рассылки промокодов при заданной вероятности продления.

## Результат

При вероятности продления 10% минимальное количество промокодов, обеспечивающее вероятность получить менее 100 продлений не выше 5%, — **1161** (`P(X < 100) ≈ 0.0498`).

## Инструменты

Python, pandas, NumPy, Matplotlib, SciPy.

## Материалы и ограничения

[Открыть Jupyter Notebook](gofast_analysis_reviewed_draft.ipynb).

Поездки одного пользователя не являются независимыми наблюдениями; результаты t-test на уровне поездок требуют осторожной интерпретации. Различия в выручке между группами не доказывают причинный эффект подписки. Данные относятся к 2021 году.

Исходные CSV не опубликованы. Для повторного запуска их необходимо поместить в локальную папку `data/`. Подробнее — в [VALIDATION.md](../VALIDATION.md).
