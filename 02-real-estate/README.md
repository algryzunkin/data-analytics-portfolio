# Рынок недвижимости — факторы стоимости жилья

**Направление:** исследовательский анализ данных · бизнес-аналитика · визуализация

## Бизнес-задача

Определить, какие характеристики квартир связаны с их стоимостью, и изучить различия между Санкт-Петербургом и соседними населёнными пунктами.

## Что сделано

- Изучено качество исходных данных из **23 699 объявлений**.
- Обработаны пропуски, типы данных и очевидно некорректные значения.
- Созданы аналитические признаки: цена квадратного метра, характеристики этажа, дата публикации, расстояние до центра.
- Исследованы распределения цен, площадей и сроков размещения.
- Оценены корреляции цены с характеристиками объектов и различия между локациями.

## Основные результаты

После базовой очистки осталось **23 633 объявления**. В очищенной выборке корреляция полной цены с общей площадью составляет около **0,65**, с жилой — **0,56**, с площадью кухни — **0,52**. Медианная длительность размещения — **95 дней**. Для Санкт-Петербурга медианная цена квадратного метра — около **104 762 ₽**.
