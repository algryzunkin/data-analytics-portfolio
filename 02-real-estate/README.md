# Исследование объявлений о продаже квартир

**Задача:** изучить факторы, связанные с ценой квартир, и различия между локациями Санкт-Петербурга и соседних населённых пунктов.

**Инструменты:** Python, pandas, NumPy, Matplotlib.

**Что сделано:**
- изучено качество исходного набора из 23 699 объявлений;
- нормализованы названия столбцов и населённых пунктов, обработаны типы и очевидно некорректные значения;
- созданы признаки цены за квадратный метр, даты публикации, типа этажа и расстояния до центра;
- исследованы распределения площадей, цен и сроков размещения;
- оценены корреляции цены с характеристиками квартиры и сравнивались локации.

**Результаты по очищенной выборке:**
- после базовой очистки осталось 23 633 объявления;
- корреляция полной цены с общей площадью — около 0.65, с жилой площадью — 0.56, с площадью кухни — 0.52;
- медианная длительность размещения — 95 дней;
- в выборке Санкт-Петербурга медианная цена за квадратный метр — около 104 762 руб.

**Ограничения:** это исторические данные, а 2019 год неполный. Пропуски `balcony` и `is_apartment` заполнены по допущению учебного решения; это явно указано в ноутбуке. Снятие объявления не обязательно означает состоявшуюся продажу.

Для локального запуска `real_estate_data.csv` должен находиться в папке `data/` рядом с ноутбуком.
