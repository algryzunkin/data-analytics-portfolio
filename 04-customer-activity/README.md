# Прогнозирование покупательской активности

Учебный проект Яндекс Практикума.

## Цель
Построить модель вероятности снижения покупательской активности в следующие три месяца и исследовать клиентов для персонализированных предложений.

## Материалы
- `analysis.ipynb` — исследование и код.
- Исходные CSV предоставляются отдельно и не включены в эту предварительную публикационную версию.

## Статус
Требуется проверка запуска на локальных датасетах, зависимостей, результатов и выводов.


**Воспроизводимость:** для полного повторного запуска требуется `phik`; результат запуска в текущем проверочном окружении не подтверждён. Данные не публикуются.
