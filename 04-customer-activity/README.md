# Покупательская активность — прогноз снижения активности клиентов

**Направление:** клиентская аналитика · машинное обучение · продуктовые решения

## Бизнес-задача

Интернет-магазину важно заранее выявлять клиентов, чья покупательская активность может снизиться в ближайшие три месяца. Прогноз может помочь сформулировать гипотезы для персонализированных предложений и удержания клиентов.

## Что сделано в проекте

- Исследование данных о поведении и активности клиентов.
- Подготовка признаков для прогнозирования.
- Построение модели оценки риска снижения активности.
- Интерпретация результатов в контексте клиентских сегментов и возможных бизнес-действий.

## Инструменты

Python, pandas, scikit-learn, phik, исследовательский анализ данных.

## Материалы и ограничения

[Открыть Jupyter Notebook](analysis.ipynb).

Ноутбук содержит сохранённые результаты и визуализации. **Полный повторный запуск в проверочном окружении пока не подтверждён:** необходим пакет `phik`. Поэтому в README не приведены непроверенные значения метрик модели.

Исходные CSV не опубликованы. Для локального запуска они должны находиться в папке `data/` рядом с ноутбуком. Зависимости перечислены в [requirements.txt](../requirements.txt), подробности проверки — в [VALIDATION.md](../VALIDATION.md).
