# Выбор нефтяного региона — прогноз прибыли и оценка рисков

**Направление:** бизнес-аналитика · машинное обучение · оценка неопределённости

## Бизнес-задача

Выбрать регион для разработки нефтяных скважин, сопоставив прогнозируемые запасы сырья, потенциальную прибыль и риск убытков. Для решения важно учитывать не только среднее ожидаемое значение, но и неопределённость прогноза.

## Что сделано в проекте

- Проанализированы данные геологоразведки по трём регионам.
- Построена модель для оценки запасов сырья.
- Рассчитана потенциальная прибыль в рамках условий учебной задачи.
- Применён Bootstrap для оценки распределения прибыли и риска убытков.
- Проведено сравнение регионов с учётом бизнес-ограничений.

## Инструменты

Python, pandas, NumPy, scikit-learn, Bootstrap.

## Материалы и ограничения

[Открыть Jupyter Notebook](analysis.ipynb).
