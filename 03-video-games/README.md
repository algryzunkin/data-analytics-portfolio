# Рынок видеоигр — продажи, сегменты и статистические гипотезы

**Направление:** рыночная аналитика · продуктовые сегменты · статистика

## Бизнес-задача

Исследовать исторические продажи видеоигр по платформам, жанрам и регионам, чтобы выявить различия рынков и проверить гипотезы о пользовательских оценках.

## Что сделано

- Обработаны пропуски, значения `tbd`, типы данных и дубликаты.
- Рассчитаны продажи по регионам.
- Исследована динамика продаж по платформам и жанрам.
- Проанализирована связь продаж с оценками пользователей и критиков.
- Выполнены проверки гипотез с использованием Welch t-test.

## Основные результаты

Для периода **2013–2016** при уровне значимости **α = 0,01**:
- Для средних пользовательских рейтингов Xbox One и PC статистически значимое различие не обнаружено (`p ≈ 0.148`).
- Для рейтингов жанров Action и Sports обнаружено статистически значимое различие (`p ≈ 1.45 × 10⁻²⁰`).

## Инструменты

Python, pandas, Matplotlib, Seaborn, SciPy.
