# Анализ рынка видеоигр

**Задача:** изучить исторические продажи игр по платформам, жанрам и регионам, а также связь продаж с оценками пользователей и критиков.

**Инструменты:** Python, pandas, Matplotlib, Seaborn, SciPy.

**Что сделано:**
- обработаны пропуски, значения `tbd`, типы данных и дубликаты;
- рассчитаны суммарные продажи по регионам;
- изучена динамика продаж по платформам и жанрам;
- сравнивались пользовательские рейтинги платформ и жанров с помощью Welch t-test.

**Результаты проверок гипотез (период 2013–2016, α = 0.01):**
- для средних пользовательских рейтингов Xbox One и PC статистически значимое различие не обнаружено (p ≈ 0.148);
- для рейтингов жанров Action и Sports обнаружено статистически значимое различие (p ≈ 1.45 × 10⁻²⁰).

**Ограничение:** датасет заканчивается в 2016 году; выводы не описывают современный рынок. Корреляции не доказывают причинность.

Для локального запуска `games.csv` должен находиться в папке `data/` рядом с ноутбуком.
