# Статус проверки перед публикацией

- GoFast — повторный запуск завершён без ошибок (по предыдущему техническому прогону).
- Недвижимость — повторный запуск завершён без ошибок.
- Видеоигры — повторный запуск завершён без ошибок.
- Нефтяные регионы — повторный запуск завершён после исправления вызова `round`.
- Покупательская активность — **полный повторный запуск не подтверждён**: необходим пакет `phik`; сохранённые результаты в ноутбуке оставлены. Команды установки устаревших фиксированных версий внутри ноутбука удалены.

Это техническая проверка выполнения, не независимая методологическая экспертиза всех выводов. В GoFast есть замечание к независимости наблюдений в проверке гипотез и к интерпретации p-value; оно требует отдельной содержательной правки.

CSV и другие датасеты в релиз не включены. Не загружайте их вручную в GitHub.

## Методологическое уточнение GoFast

В интерпретации длительности поездок явно отмечена зависимость повторных поездок одного пользователя. Тест на отдельных поездках сохранён как учебный расчёт, но не представлен как независимое доказательство различий на уровне пользователей. Интерпретация выручки ограничена ассоциацией, а не причинным эффектом подписки. Полный повторный запуск после этих текстовых правок не выполнялся.
