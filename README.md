# Портфолио аналитических проектов

**Data Analyst · Business Analyst · Product Analyst**

Пять учебных проектов по исследованию данных, статистике, клиентской аналитике и машинному обучению. Акцент — на постановке бизнес-задачи, выборе метода и интерпретации результата.

## Проекты

| Проект | Бизнес-задача | Методы и навыки |
|---|---|---|
| [GoFast — аренда самокатов](01-gofast/) | Исследовать поведение пользователей с подпиской и без неё, оценить выручку | Сегментация, расчёт выручки, проверка гипотез |
| [Рынок недвижимости](02-real-estate/) | Определить характеристики, связанные с ценой жилья | EDA, очистка данных, корреляционный анализ |
| [Рынок видеоигр](03-video-games/) | Сравнить продажи по регионам, платформам и жанрам | Анализ рынка, визуализация, статистические тесты |
| [Покупательская активность](04-customer-activity/) | Оценить риск снижения активности клиентов | Клиентская аналитика, прогнозирование, ML |
| [Выбор нефтяного региона](05-oil-region/) | Сопоставить прибыль и риски выбора региона | Регрессия, Bootstrap, оценка рисков |

## Инструменты

**Python:** pandas, NumPy, Matplotlib, Seaborn, SciPy, scikit-learn.  
**Подходы:** исследовательский анализ данных, обработка пропусков, визуализация, статистические гипотезы, прогнозные модели, бизнес-интерпретация.

## Как смотреть

Откройте README интересующего проекта, затем Jupyter Notebook (`.ipynb`) с кодом, графиками и сохранёнными результатами.

## Данные и воспроизводимость

Исходные CSV не опубликованы. Для повторного запуска необходимы соответствующие локальные датасеты в папке `data/` каждого проекта. Зависимости перечислены в [requirements.txt](requirements.txt).

Четыре проекта ранее успешно выполнялись с исходными данными. Полный повторный запуск проекта покупательской активности пока не подтверждён из-за отсутствующей в проверочном окружении библиотеки `phik`. Подробности и методологические оговорки — в [VALIDATION.md](VALIDATION.md).

*Проекты выполнены в учебных целях; результаты не являются подтверждением промышленного внедрения моделей.*
