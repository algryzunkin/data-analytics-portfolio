## Данные и воспроизводимость

Исходные CSV не опубликованы. Ноутбуки содержат сохранённые результаты и визуализации. Для повторного запуска требуются исходные данные, размещённые локально в папке `data/` соответствующего проекта; имена файлов указаны в коде. Папки `data/` исключены из Git через `.gitignore`.

Установите зависимости командой `pip install -r requirements.txt` и запускайте ноутбук из его папки. **Четыре проекта были технически выполнены повторно; полный повторный запуск проекта «Покупательская активность» не подтверждён из-за отсутствия `phik` в проверочном окружении.** Это ограничение не означает, что сохранённые результаты проверены независимо.
